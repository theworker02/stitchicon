# stitchicon

Stitch encode/decode helpers for icon payloads in pipelines.

**Site:** https://theworker02.github.io/stitchicon/

## Install / run

```bash
git clone https://github.com/theworker02/stitchicon.git
cd stitchicon
node src/cli.js
node --test
```
